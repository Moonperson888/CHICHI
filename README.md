# CHICHI
File extractor written in C++
unzip.cpp is the code for the program main.cpp is the text extractor i made that is not on github


To use, press super + R and type in that box "Shell:sendto" hold right click on the exe and drag it in there press create shortcuts and change the icon and name to what you would like!
then right click the zip you would like to extract then press "Show More Options" then send to then click CHIExtractor or whatever you set the shortcuts name to.
